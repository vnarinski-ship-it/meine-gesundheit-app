# OCR Hub

Separate Android-App für lokale Dokumentenverarbeitung.

## V0.1
- Import von Fotos und PDFs
- verschlüsselte Ablage des Originals
- lokale OCR mit Google ML Kit Text Recognition
- mehrseitige PDFs werden lokal seitenweise gerendert und erkannt
- erkannter Text ist korrigierbar
- strukturierter JSON-Export
- Übergabe an Meine Gesundheit oder Android-Teilen
- keine Werbung

## Datenschutz
OCR läuft lokal auf dem Android-Gerät. Eine spätere KI-Bewertung wird separat und nur nach ausdrücklicher Nutzeraktion ergänzt.
